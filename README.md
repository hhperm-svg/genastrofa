# 🏗 ГЕНАСТРОФА: Симулятор соседа сверху
### Интерактивная 3D-игра (Advergame) и промо-лендинг для «АльфаСтрахования»

Проект разработан в изометрической стилистике диорамы («Котастрофа» / *Untitled Goose Game* style) с использованием **Three.js (WebGL)**, процедурной физики, процедурного звука Web Audio API и сквозной конверсионной воронкой в продукт **«Страхование квартиры» от «АльфаСтрахования»**.

---

## 🎮 Ключевые возможности и механики

1. **3D-Диорама квартиры (17 × 12 м)**:
   - 3 функциональные зоны: **Гостиная**, **Кухня**, **Ванная** с объёмными надписями на полу.
   - Система «срезанных стен» (cutaway view) в зависимости от угла поворота камеры.
   - Свободный орбитальный осмотр мышью с плавным следованием (`lerp`) за персонажем.

2. **14 составных 3D-моделей с двумя состояниями (Целый / Разрушенный)**:
   - 75" OLED-телевизор с паутиной трещин и искрами
   - Итальянский изумрудный диван с разлетающимися подушками и пружинами
   - Журнальный столик с MacBook Pro и чайным сервизом
   - Крупный фикус в терракотовом кашпо с высыпанием земли на паркет
   - Стеллаж с вазами династии Мин и книгами
   - Скрытая магистраль отопления в стене (точка для бурения буром)
   - Чугунный радиатор отопления с вылетающим вентилем
   - Бирюзовый кухонный гарнитур с варочной панелью и мойкой
   - Самогонный аппарат «Первач-Люкс» со взрывом и клубами пара
   - Умный двухкамерный холодильник BORK с разлетающимися продуктами
   - Чугунная ванна на ножках с тропическим душем и уточкой
   - Дизайнерский унитаз с инсталляцией
   - Стиральная машина 1400 об/мин с вибрирующей тумбой и зеркалом
   - Главный стояк водоснабжения с фонтаном до потолка

3. **Главный герой — сосед Геннадий**:
   - Анимированная составная модель в тельняшке, синих трико с лампасами, тапках и строительной каске с рабочим фонарём.
   - Экипировка: перфоратор «Макита-Ультра», газовый ключ и 24-кг чугунная гиря.
   - Процедурные анимации: бег (`WASD` + `Shift`), прыжок (`Space`), непрерывное бурение (`Q`), сброс гири (`F`), удар по батарее / шансон (`R`), контекстный удар ключом (`E`).
   - Всплывающие комикс-бабблы над головой с репликами Геннадия.

4. **Физика и симуляция стихий**:
   - **Физика затопления (Water Level System)**: поднимающийся зеркальный полупрозрачный меш воды с синусоидальной рябью волн.
   - **Цепное комбо «ВОДА + ТОК = КОРОТКОЕ ЗАМЫКАНИЕ (x2.5)»**: синие 3D-дуги молний, взрывающие соседние электроприборы.
   - **Шкала «Кураж Капремонта»**: комбо-множитель от `x1.0` до `x5.0`.

5. **Противники и умные системы**:
   - **Робот-пылесос «ЧистоБот-9000»**: патрулирует квартиру, а при сближении таранит Геннадия со станом на 1.5 сек. Уничтожается прыжком с гирей (`+45 000 ₽`).
   - **Умные датчики «АльфаСтрахование Умный Дом»**: предупреждают сиреной за 5 секунд. Если не сбить — включают **Красный Купол Альфа-Защиты**, обнуляющий любой урон (*«СТРАХОВКА СРАБОТАЛА: 0 ₽ УЩЕРБА!»*).

6. **Конверсионная воронка и интеграция бренда**:
   - **Кассовый чек катастрофы**: интерактивный тумблер *«У меня есть полис АльфаСтрахование»*, перечёркивающий сумму ущерба в **0 ₽ из вашего кармана**.
   - Промокод `GENA15` (-15%) с быстрым копированием.
   - Кнопка прямого перехода в официальный калькулятор: [alfastrah.ru/.../calculator/](https://www.alfastrah.ru/individuals/housing/flat/calculator/).
   - Встроенный интерактивный пре-калькулятор на лендинге.

## 🚀 Как развернуть на Vercel

### Вариант 1: Через Vercel CLI (самый быстрый)
1. Установите Vercel CLI, если ещё не установлен:
   ```bash
   npm i -g vercel
   ```
2. Перейдите в папку проекта:
   ```bash
   cd genastrofa
   ```
3. Выполните команду деплоя:
   ```bash
   vercel
   ```
   (Для продакшн-деплоя: `vercel --prod`)

### Вариант 2: Через GitHub / GitLab
1. Создайте репозиторий на GitHub.
2. Сделайте push содержимого папки `genastrofa`.
3. В панели [vercel.com](https://vercel.com/) нажмите **«Add New... -> Project»** и импортируйте репозиторий.
4. Vercel автоматически определит проект как статический HTML/JS сайт и задеплоит его за несколько секунд!

## 💻 Локальный запуск
Просто откройте файл `index.html` в любом современном браузере с поддержкой WebGL (Chrome, Edge, Firefox, Safari) или запустите локальный сервер:
```bash
npx serve .
# или
python -m http.server 8000
```
